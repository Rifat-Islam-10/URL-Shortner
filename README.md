# URL-Shortener
A simple and user-friendly URL Shortener desktop application built with Python and Tkinter. The application allows users to enter a long URL,resource an alias and generate a shorter, shareable link through a URL-shortening API, with the result displayed directly in the graphical interface.


~Features:

 🔗 Convert long URLs into short, shareable links
 🖥️ Clean and simple Tkinter GUI
 ⚡ API-based URL shortening
 📋 Easy-to-view generated shortened URL
 ❌ Input validation and error handling
 🧩 Lightweight desktop application

🛠️ Technologies Used:

-Python
-Tkinter – GUI development
-Requests – API communication
-URL Shortening API – Generates shortened URLs

🚀 How It Works:

1. Enter the original URL into the application.
2. Click the **Shorten URL** button.
3. The application sends the URL to the shortening API.
4. The API processes the request and returns a shortened URL.
5. The generated link is displayed in the application for the user to copy and use.
